存入后会出现喺「全部汤谱」，可收藏、可搜寻、可删除。清除浏览器资料会一并清走，重要配方建议自己另存一份。

呢个系咩

一个单文件、离线可用嘅汤谱速查页。全部 19 款汤、样式同功能都内嵌喺呢个 .html 入面，唔使上网、唔使装嘢、唔会传任何资料出去。

其中「沙参玉竹淮山百合煲瘦肉」有公众号版同健康广东版两个略有出入嘅版本，拆成两张卡方便对照，所以卡片总数系 20 张，汤谱计 19 款。

点样当 App 用

  • iPhone / iPad：用 Safari 打开呢个文件 → 底部分享 ⬆️ → 「加入主屏幕」。
  • Android：用 Chrome 打开 → 右上 ⋮ → 「加到主屏幕 / 安装应用」。
  • 之后桌面会有个图标，点开全屏，飞机模式都查到。
  • 建议将个 .html 摆去手机「文件」或者网盘同步，换机都仲喺度。

功能

  • 搜汤名／材料／功效／时节，即时筛
  • 按「每日一膳正栏 / 同期专家推荐 / 我嘅汤谱 / 已收藏」分类
  • 点卡片展开，睇材料、做法、点评、禁忌同原文链接
  • 份量换算：原方多系 3 人份，按 4 人 / 5 人一键放大克数
  • ☆ 收藏、自己新增汤谱（存喺浏览器本机）

净系收煲汤 / 炖汤。糖水、粥、羹、焖菜、炒菜，同埋龙舟水／芒种嘅旧文都剔走咗，列喺底下。

有确切日期嘅按日期（虫草花汤约 11/10、霜降 10/23、小雪 11/22）；其余按文中「11 月中旬」「立冬后」「霜降后」归入，公众号冇逐篇标发布日。

两句提醒

汤谱系日常食养参考，唔替代睇医生。感冒发热、怀孕、慢性病、长期服药、细路同老人家，煲之前按每款写低嘅禁忌对一对，唔确定就问医师。

呢份同时系 Android APK 内嵌页，亦可以单独喺 iPhone／电脑浏览器打开。内置 20 张卡离线照用；一有网络就自动去公网攞 soups.json，版本号唔同先覆盖，同步完 cache 落本机，断网都系最新。改汤谱净系改网上嗰份 JSON、改个 version 就够，唔使重新出 APK、唔使重装；只有改界面／功能先要重新 Build。

Android 版用原生连线去攞嘢，唔使服务器开 CORS；iPhone／浏览器版用 fetch()，所以个源要系 https 且开咗 CORS（GitHub raw、jsDelivr、GitHub Pages 都有 Access-Control-Allow-Origin: *，直接用得；自己部 NAS／python -m http.server 就未必）。

收录口径

净收广东省中医院微信公众号「每日一膳」正栏嘅煲汤／炖汤。健康广东、南方日报／南方+、南都 N 视频、今日头条、腾讯新闻一律唔再另开新卡 —— 佢哋多数系同一篇同步推送或者转载，照收会变几张一样嘅卡。

做法系「认方唔认篇」：同一汤名＋核心材料组只留一张；其他媒体登过嘅净记入卡片嘅来源备注做互证。糖水、粥、羹、焖菜同旧季度文章一律唔收。

现有 19 张卡一张唔删、id 唔变（已收藏 ☆ 唔会乱），只系补咗来源标记；其中「沙参玉竹淮山百合煲瘦肉」两张系同一方嘅公众号版／转载版，已标为同一组，对照用，唔当两款新汤。
